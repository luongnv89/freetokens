A bracket around Free.

Design Concept

The mark is a stem-and-bars F — the initial of Free — drawn in a single weight with rounded terminals. The trailing half-bracket at its right is the code bracket developers live in: the site is for people building on free tiers.

It is single-colour — the site’s accent green, #137236 in the light scheme and #22c55e in the dark — so it works as a UI glyph beside text. The bracket sits at 55% opacity, giving hierarchy without a second hue.

The wordmark is set in Lora 600, the site’s display face used for headings, so the lockup matches the page h1.
